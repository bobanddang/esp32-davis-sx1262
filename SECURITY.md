# Security Policy

## Supported Versions

Currently, only the latest release (or the main branch) is actively supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities by opening a public Issue. 

Instead, please use GitHub's Private Vulnerability Reporting feature to keep the details hidden until a fix is ready:

1. Go to the **Security** tab of this repository.
2. Click **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.

I will try to acknowledge your report within a few days and work with you to patch the issue.
